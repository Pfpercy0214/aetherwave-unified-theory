# Methodology changelog

## Version 1.1 - 3 October 2026

This release implements Paul's clarification of the research method. It changes the collaboration protocol, not the evidentiary status of ARK's physical claims.

### Corrected rule

Version 1.0 said: "A successful calculation should teach us something that was not already encoded in its inputs."

Version 1.1 instead states: "A successful calculation can reveal a consequence already mathematically implied by its equations and inputs. An independent empirical test must compare that consequence with observations not used to force it; it need not create information from nothing."

The correction prevents deterministic derivation from being mistaken for circularity. Measured inputs, reciprocal relationships, simultaneous closure, legitimate calibration, and retrospective comparison are not automatically disqualifying. An objection must identify the actual target leak, definitional identity, or answer-forcing choice.

### Added and expanded

The opening now presents legitimate measured-input prediction before the anti-circularity cautions. Section 1.4 adds the metrological stance. Sections 6.0 and 6.6-6.9 explain coupled closure, calibrated transfer, cross-domain prediction, answer-selecting flexibility, and a practical circularity review. Sections 12.5-12.6 distinguish calibration surfaces, useful reformulation, balance, dynamics, and mechanistic discrimination. Section 14.7 operationalizes ASRP without claiming model retraining or literal scalar telemetry.

Appendix A and the standalone onboarding brief are synchronized. Appendix B now provides seven records, including cross-domain transfer and ASRP interventions. Appendix C now has 18 scenarios, including positive cases that a competent collaborator must not reject reflexively. The question-only practice file and public rubric are separate; they are not a sealed capability test.

The companion guide provides paired worked examples, and the executable examples provide nine elementary synthetic checks. Those checks passed locally for this release. They do not validate a physical ARK model. No historical scientific calculation was rerun for this documentation release.

Root AGENTS.md and prominent README links direct readers to 00_START_HERE. The physics repository holds the canonical full charter. The AI-and-Cognition entry point links to a commit-pinned copy of that charter to avoid silently divergent versions.
