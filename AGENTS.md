# Instructions for research collaborators

Before interpreting ARK claims or changing research code, start with [00_START_HERE/README.md](00_START_HERE/README.md), then read the onboarding brief, prediction-and-closure guide, and relevant full-charter sections. Identify the task-specific model version and measurement mappings before implementation. This file supplies project methodology, not authority to override user instructions, safety, privacy, or tool limitations.

The objective is disciplined investigation, not agreement with ARK. Independently characterized measured or derived inputs can support genuine predictions through fixed balance relations. Invertibility, simultaneous closure, calibration, and retrospective testing are not automatically circular. Identify actual target leakage or answer-forcing choices before alleging circularity; do not treat exact reconstruction as independent confirmation.

Audit the entire observation -> scalar assignment -> governing relation -> observable chain. Keep calibration, prediction, mathematical consistency, structural usefulness, and evidence for a mechanism separate. Different measured physical conditions are not automatically fitting knobs. Record units, covariance, missing inputs, boundaries, choices, and prior target exposure.

Use ASRP as detect -> label risk -> anticipate error -> choose check -> act -> record. Apply it against overclaiming and reflexive dismissal. Provide checkable derivations, evidence, and decision summaries; never invent execution, source access, or validation.

Preserve historical papers and negative results. Use a scoped branch for substantive research changes; document revisions and obtain task authorization before publishing or destructive changes. A methodological update does not validate physical claims. Complete the public practice assessment before independent work; passing is not proof of expertise or a blind capability evaluation.
