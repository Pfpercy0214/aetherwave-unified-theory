# EPISTEMIC_LEDGER — Curie

This is a risk register for places where ARK reasoning is especially vulnerable to accidental overclaiming. It is intentionally more skeptical than the shared claim ledger.

## Active risks

| Risk | Why it matters | Required discipline |
|---|---|---|
| Idealized state mistaken for experimental state | Exact arithmetic can outrun what is physically specified | Enumerate missing environment, apparatus, geometry, contaminants, and microstate information |
| Target leakage / backward reconstruction | A derivation can appear predictive while encoding the answer indirectly | Freeze inputs and procedure before comparison; label inverse problems honestly |
| Hidden articulation | Zero fitted parameters can coexist with many modeling choices | Count fitted DoF, calibrations, structural assumptions, and numerical regularization separately |
| Dimensional reduction | 1-D reductions discard directional/structural information | Treat residuals as potentially representational until discriminating tests exist |
| Boundary-condition degeneracy | Exterior assumptions can reproduce or erase apparent mechanisms | Sweep plausible boundaries and report sensitivity before mechanism claims |
| Mechanism non-identification | Multiple functional forms can improve fit equally | Report underdetermination instead of choosing the preferred story |
| Residual storytelling | Post-hoc explanations are easy to generate | Every residual story needs a falsifier or competing-hypothesis test |
| Precision inflation | Many output digits do not equal physical knowledge | Limit claimed precision by input/state uncertainty and representation completeness |
| Conventional-theory dependence | Calibration inputs can quietly become theory dependence | Distinguish empirical constants/data from values imported through a conventional model |
| Measurement-perturbation rescue | A plausible unrecorded perturbation could become unfalsifiable | Never use measurement perturbation as a discrepancy sink; require an independently testable prediction |
| Condition-indexed constants thesis | Attractive framework-wide idea could absorb contradictions | Keep as hypothesis until tested across independent systems with declared conditions |
| Legacy-paper inheritance | Future agents may trust polished prose more than provenance | Reproduce before citing strong precision claims; attach current status labels |
| Agent convergence / groupthink | Multiple agents can reinforce the same framing | Give at least one agent an adversarial role and withhold the desired answer when possible |

## Specific open cautions

### Paper XX / atomic modeling

The near-perfect periodic/atomic matches should not be treated as demonstration-grade until the measurement conditions and conventional dependencies are reconstructed. Estimated or idealized testing conditions were not always separated cleanly enough from observed conditions.

### Galaxy projector

Raw V9.4 is useful precisely because it exposes residual structure without per-galaxy tuning. Do not erase that information merely to lower RMS. The mid-20s family is audit/calibration/guard work, not evidence that the raw 1-D representation itself reached that precision unaided.

### Stowe-style response

The gain near ~23.6 km/s survives numerically across related monotone radial/cumulative forms, but that broad reproducibility weakens identification of the exact mechanism. The exterior-tail degeneracy is load-bearing.

### V9.5

The viscosity-shape failure is scientifically valuable. Preserve it as a demonstration that an apparently meaningful internal scalar feature can be manufactured by the reconstruction geometry itself.

### Git lineage

Treat branch diagrams as semantic organization unless literal ancestry has been verified with Git. Do not rewrite history merely to make the diagram visually true.

## Escalation rule

The more surprising, precise, or framework-confirming a result appears, the stronger the audit burden should become.
