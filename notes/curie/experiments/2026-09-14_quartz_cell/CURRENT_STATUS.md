The exact rigid-tetrahedron model leaves a **41.3029% relative strain-tensor norm residual** against the specified homogeneous static piezoelectric control. This is not a measured resonance error or a fraction of physical states. The model fixes a shear ratio of 0.6576783 where the imported control requires 0.1572540.

Allowing internal angular changes while holding Si–O lengths at first order removes that kinematic obstruction. This is a feasibility result, not a predicted atomic response. An illustrative displacement selected by an explicit geometric least-squares criterion must not be mistaken for the motion selected by physical forces.
